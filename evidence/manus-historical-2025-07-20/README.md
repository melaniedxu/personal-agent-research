Archive filenames say 2025-07-20. The [provenance manifest](PROVENANCE.json)
pins their repository commit and hashes; no capture procedure or production
version is authenticated.

The file named `2025-07-20_prompt.txt` is a capability essay that says it will not
disclose proprietary architecture. Do not treat its name as proof of a real
system prompt. The persona and prompting-guide files are auxiliary material.
Even the more concrete module/tool files do not establish today's Cue harness.
